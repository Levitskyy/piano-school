# AGENTS.md — Piano School

## Что это за проект

Сайт преподавателя фортепиано для продажи онлайн-курсов, разовых индивидуальных уроков и пакетов занятий. Ученик оплачивает на сайте и сразу получает доступ к курсу или запись на урок — без ручного участия преподавателя.

**Главный источник требований:** [docs/piano-school-project.md](docs/piano-school-project.md) — стартовый бриф по результатам интервью. Прочитайте его целиком перед любой работой над проектом. Ниже — только краткая шпаргалка.

## Ключевые факты

- **Цель:** рабочий MVP за 1–2 месяца, затем развитие по обратной связи.
- **Аудитория:** русскоязычная по всему миру → разные часовые пояса и валюты. Язык интерфейса — русский (предложение), с заделом на локализацию.
- **Продукты:** видеокурс (модули → уроки, ноты, литература), разовый урок, пакет уроков. Подписки в MVP нет.
- **Роли:** гость, ученик, родитель (владелец аккаунта с профилями детей — предложение), преподаватель/админ.
- **Подтверждённый стек:** Next.js (React, TypeScript) + FastAPI (Python, Pydantic, OpenAPI), PostgreSQL + SQLAlchemy/Alembic, Redis + ARQ, S3-хранилище, HLS-видео, REST + типизированный TS-клиент по OpenAPI. Каркас уже поднят: см. [README.md](README.md).
- **Дизайн:** минимализм, академичный классический стиль, засечки в заголовках, сдержанная палитра, много воздуха, без визуального шума.
- **Фундамент зафиксирован 18.11.2026:** [docs/project-foundation.md](docs/project-foundation.md). Это единственный источник утверждённых решений.
- **Прод развёрнут на VPS** (`193.233.88.115`, код в `/opt/piano-school`, Docker Compose + nginx). Изменения попадают на сервер **только через merge PR в `master`**: CI проверяет коммит, затем workflow `Deploy to VPS` сам подтягивает его и перезапускает стек. Подробности — [docs/development-workflow.md](docs/development-workflow.md) и [docs/production-deployment.md](docs/production-deployment.md).

## Приоритет MVP (из брифа)

1. Лендинг, каталог, страницы курсов и тарифов, юридические страницы.
2. Регистрация/вход, личный кабинет.
3. Курсы: плеер, материалы, прогресс.
4. Оплата минимум через одного провайдера, автоматическая выдача доступа через webhooks.
5. Календарь слотов с локальным временем, запись на урок, остаток по пакету.
6. Базовая админ-панель и email-уведомления.

Домашние задания с обратной связью (плеер, оценки, обсуждения), приём международных карт, мультивалютные платежи и профили детей — **этап 2**, не MVP. Упрощённые ДЗ (файл + текстовый комментарий) входят в MVP.

## Правила работы с брифом

- Пункты, помеченные **(предложение)**, не утверждены. Не принимайте их как готовое решение без подтверждения пользователем.
- Вопросы №1 (юрлицо и платежи) и №7 (команда и бюджет) брифа закрыты: ИП/самозанятый РФ, solo-разработка с AI-агентом. Остальные открытые вопросы ведутся в [docs/project-foundation.md](docs/project-foundation.md), раздел 6.
- Если задача затрагивает оплату, доступы к контенту или данные детей — действуйте осторожно и уточняйте неопределённости.
- Терминологию и формулировки берите из брифа, чтобы не расходиться с заказчиком.
